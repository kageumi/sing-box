# sing-box

A personal VLESS + REALITY installation script. Prints a VLESS URL and single-proxy configurations for Mihomo and sing-box after installation.

Defaults: port `443`, server name `gateway.icloud.com`, and fingerprint `chrome`. UUID v4, REALITY keys, and a short ID are generated automatically.

## Installation

Requires Linux, root privileges, systemd, and apt-get or yum. The server must be able to access GitHub and package repositories.

Run as root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/irasutoya/sing-box/main/install.sh)
```

To specify options, download the script first:

```bash
curl -fsSL https://raw.githubusercontent.com/irasutoya/sing-box/main/install.sh -o install.sh
sudo bash install.sh -port 8443
```

Supported architectures: amd64, arm64, armv7, armv6, 386, mips64le, mipsle, ppc64le, riscv64, s390x, and loong64.

## Options

```text
Usage: bash install.sh [options]

  -port        Listen port (1-65535, default: 443)
  -uuid        UUID v4 (generated by default)
  -uninstall   Uninstall and remove the binary and configuration
  -help        Show help
```

`-port` and `-uuid` require values. Ports are parsed as decimal numbers: `00443` is equivalent to `443`.

UUID v4 format: `xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx`. Each `x` is a hexadecimal character; `y` is `8`, `9`, `a`, or `b`. Letters are case-insensitive.

```bash
sudo bash install.sh -port 8443 -uuid 01234567-89ab-4def-8123-456789abcdef
```

## Clients

The following templates use `${...}` placeholders that are replaced during installation. If public IP lookup fails, replace `localhost` with the server IP before importing.

### VLESS

```
vless://${UUID}@${SERVER_IP}:${PORT}?encryption=none&flow=xtls-rprx-vision&security=reality&sni=${DOMAIN}&fp=chrome&publicKey=${PUBLIC_KEY}&shortId=${SHORT_ID}#${SERVER_IP}
```

### Mihomo

```yaml
proxies:
  - name: ${SERVER_IP}
    server: ${SERVER_IP}
    port: ${PORT}
    type: vless
    uuid: ${UUID}
    tls: true
    tfo: false
    udp: true
    flow: xtls-rprx-vision
    reality-opts:
      public-key: ${PUBLIC_KEY}
      short-id: ${SHORT_ID}
    servername: ${DOMAIN}
    client-fingerprint: chrome
    network: tcp
```

### sing-box

```json
{
  "outbounds": [
    {
      "type": "vless",
      "tag": "${SERVER_IP}",
      "server": "${SERVER_IP}",
      "server_port": ${PORT},
      "uuid": "${UUID}",
      "flow": "xtls-rprx-vision",
      "tls": {
        "enabled": true,
        "server_name": "${DOMAIN}",
        "utls": {
          "enabled": true,
          "fingerprint": "chrome"
        },
        "reality": {
          "enabled": true,
          "public_key": "${PUBLIC_KEY}",
          "short_id": "${SHORT_ID}"
        }
      }
    }
  ]
}
```

## Management

```bash
# Status
systemctl status sing-box

# Logs
journalctl -u sing-box -n 50 --no-pager

# Restart
systemctl restart sing-box

# Help
bash install.sh -help

# Uninstall
sudo bash install.sh -uninstall
```

- Binary: `/root/sing-box/bin/sing-box`
- Configuration: `/root/sing-box/config/config.json`
- Service: `/etc/systemd/system/sing-box.service`

Reinstalling overwrites the configuration and generates new keys. Update clients accordingly. Uninstalling removes the binary and configuration; back up any files you need to keep first.

If installation fails, check the terminal errors. If connections fail, check the service status and confirm that the listening port is allowed by the firewall and security group.
